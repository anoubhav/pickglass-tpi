# paper/figs/

Output folder of the figure scripts in `paper/tools/`, `methods/make_figs.py`, `vlm/make_scaffold_figs.py`,
`camera_aug/make_camera_fig.py`, `genai_sr/make_figure.py`, `gpu_results/make_paper_figs.py` and others (git-ignored
except this file). The paper's own figures are not in the repository because several of them show the mill's photos;
the charts can be regenerated from the released CSVs (see the top-level README).
